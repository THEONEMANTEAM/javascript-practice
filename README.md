# JavaScript Practice: Functions, Closures & Memoization

Exercises from my JavaScript learning roadmap (Days 13-18), following javascript.info.
I'm learning backend development (Node.js) and building these to understand the core patterns.

## What's in here

**Recursion:** `pow(x, n)` and `fib(n)`, with a base case and a recursive step
 **Memoization:** a caching decorator that remembers past results using a `Map`
 single-argument version
 multi-argument version using rest params (`...args`), spread, and `.join()`
 applied to recursive Fibonacci
 **`once(func)`:** a decorator that lets a function run only one time
**Factory functions:** toggle, ID generator, and running accumulator, each with private state

## Concepts practiced

Closures, higher-order functions, rest/spread, recursion and the call stack.
